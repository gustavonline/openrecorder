Support

OpenRecorder is a free preview maintained by one person. Questions and bug reports go to GitHub issues; please read the install guide and update, uninstall and recovery first.

What to include

  • Your operating system and chip, and the OpenRecorder version (Settings → About).
  • What you did, what you expected, what happened.
  • The output of OpenRecorder --doctor, which checks the bundled media helper and touches no device.

Do not attach recordings, access codes, links or your journal without reading them first.

Not supported

  • Windows and Linux builds (experimental, never run on hardware).
  • Public sharing on networks that block Cloudflare tunnels.
  • Notarization: the macOS app is not notarized.

Security

Report security problems privately as described in SECURITY.md.
