Privacy

This describes how the software behaves. It is a plain description by the author, not a legal document; the author has not had it reviewed by a lawyer.

On your computer

OpenRecorder records your screen, camera and microphone only when you press Record, and only after your operating system lets it. Recordings, the library index and settings are files in your own folders. There is no account, no analytics, no crash reporting and no cloud storage, and OpenRecorder does not send your recordings, library or usage data to the author or upload them anywhere. Two optional features, described below, do involve other parties: sharing and the agent plugin.

Sharing

If you create a share link, the recording you chose is served from your own computer through an optional Cloudflare Quick Tunnel that you install and run (cloudflared, not bundled; it connects to Cloudflare to create the tunnel). Whoever has the link and the access code can watch that one video while the link lasts, and Cloudflare carries that traffic under its own terms and privacy policy. The link and code are kept in memory only and end when you stop the share, archive the recording, quit OpenRecorder or the tunnel drops; bytes a guest already received cannot be recalled.

Agents

If you install the plugin, the AI host you use (for example Codex or Claude Code) receives what the plugin’s tools return: recording titles, file names and information, library state, and a share link and access code when you ask for a share. The agent can also open, organise and share recordings through those tools. The tools cannot start a recording; that limit applies to the tools, not to an agent that can run shell commands or control your computer. What the host and its model provider do with this information is governed by their own terms and privacy policies, not by OpenRecorder.

This website

This site is static pages served by Cloudflare. It sets no cookies, loads no third-party scripts, fonts or trackers, and stores only your light/dark choice in your browser.
